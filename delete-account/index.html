Delete Data or Account

Last updated: September 5, 2026

The current public release stores gameplay progress locally. Cloud Save and account sign-in are disabled. Separate instructions below are retained for players who used test-version Cloud Save or a Unity Player Account.

Delete this device’s game progress

  1. Open Smeltara and open Settings.
  2. Select Start Over, then confirm.
  3. The current release resets this device’s progress. In a test version with account sign-in, choose This Device Only when signed in.

This does not delete an existing test-version cloud backup, withdraw advertising privacy choices or delete data already held by Google. Use Privacy Choices where available and Google’s privacy controls for advertising-service requests.

Test versions: delete Smeltara Cloud Save data

  1. Connect to the internet and sign in to the Unity Player Account that owns the backup.
  2. Open Settings → Start Over and confirm.
  3. Choose Device + Cloud.
  4. Smeltara deletes both cloud save slots first. The device resets only after the service confirms deletion. If confirmation fails, nothing is reset; retry later.

This removes Smeltara gameplay files from Unity Cloud Save but does not delete the Unity Player Account, which may be used by other applications.

Test versions: delete the Unity Player Account

Open Unity Player Accounts, sign in and use its Support/account-deletion option. Unity owns the cross-application account relationship. Delete Smeltara Cloud Save data separately using the steps above.

Need help?

If you cannot access the in-game deletion route, email nacar.dev@gmail.com with “Smeltara Data Deletion” in the subject. Do not send your password or sign-in code. We may need enough information to locate the relevant Smeltara data without collecting more information than necessary.
