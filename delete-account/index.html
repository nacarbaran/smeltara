Delete Data or Account

Last updated: September 1, 2026

Smeltara local progress, Smeltara Cloud Save files and your Unity Player Account are three different things. Choose the scope you want below.

Delete this device’s game progress

  1. Open Smeltara and open Settings.
  2. Select Start Over, then confirm.
  3. If you are signed out, the device resets. If you are signed in, choose This Device Only.

This does not delete an existing cloud backup.

Delete Smeltara Cloud Save data

  1. Connect to the internet and sign in to the Unity Player Account that owns the backup.
  2. Open Settings → Start Over and confirm.
  3. Choose Device + Cloud.
  4. Smeltara deletes both cloud save slots first. The device resets only after the service confirms deletion. If confirmation fails, nothing is reset; retry later.

This removes Smeltara gameplay files from Unity Cloud Save but does not delete the Unity Player Account, which may be used by other applications.

Delete the Unity Player Account

Open Unity Player Accounts, sign in and use its Support/account-deletion option. Unity owns the cross-application account relationship. Delete Smeltara Cloud Save data separately using the steps above.

Need help?

If you cannot access the in-game deletion route, email nacar78@gmail.com with “Smeltara Data Deletion” in the subject. Do not send your password or sign-in code. We may need enough information to locate the relevant Smeltara data without collecting more information than necessary.
